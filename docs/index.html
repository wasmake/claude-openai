Source install. No npm publish.

Run npm start in one terminal (it stays foreground), then send requests from a second terminal.

terminal 
# Clone from GitHub
git clone https://github.com/wasmake/claude-openai.git
cd claude-openai
npm ci && npm run build

# Start locally (keeps this terminal busy)
npm start

# In a second terminal, use any OpenAI client
curl http://localhost:3456/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-openai/claude-sonnet-5","messages":[{"role":"user","content":"Hello!"}]}'

Official CLI

Uses claude --print as a subprocess. No OAuth extraction or private API scraping; review Anthropic terms before use.

$ 

Usage Tracking

GET /v1/usage shows token counts and estimated costs using official Anthropic pricing. Estimates only, not billing.

[=]

Streaming

SSE streaming for real-time responses.

Team Auth

Optional API key authentication for shared deployments. Set API_KEYS env var to require Bearer tokens.

Current Models

Fable 5, Opus 4.8, Sonnet 5, and Haiku 4.5. Provider-prefixed IDs are supported for compatibility.
